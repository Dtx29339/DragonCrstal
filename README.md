# 龍域幻晶:不屈的雙刃 Dragonrealm Crystal The Unyielding Blades

## 遊戲介紹
使用 Unreal Engine 5 開發的 2D 橫向動作遊戲。

## 核心玩法
- 雙角色切換系統
- 近戰攻擊與連段
- 格擋、閃避與跳躍
- 遠程射擊

## 開發工具
- Unreal Engine 5
- PaperZD
- GitHub Desktop

## 開發狀態
- 目前持續開發中。
- 11/9 製作連招動畫，尚未有HITBOX、ResetState函式。
- 11/11 製作格擋與閃避，並於昨日將兩個角色子藍圖指向一個狀態機，使兩個角色共用一個狀態機。
